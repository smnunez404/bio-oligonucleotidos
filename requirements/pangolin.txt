# DOS TRAMPAS DOCUMENTADAS, las dos capaces de arruinar una corrida en silencio:
#
# 1) KMP_AFFINITY=disabled es OBLIGATORIO. Sin esa variable, importar torch aborta
#    con un error de OpenMP que no menciona la causa. El pipeline lo verifica y
#    falla con mensaje claro (pipeline/pangolin_cross.require_affinity_disabled).
#      KMP_AFFINITY=disabled python pipeline/run_pangolin_cross.py
#
# 2) Pangolin solo puntúa las bases CENTRALES: descuenta 5000 nt de contexto a cada
#    lado y devuelve len(seq) - 10000 scores. Con una región de 10.001 nt devolvería
#    UN solo punto, sin avisar. De ahí que las corridas usen padding >= 6000.
